# Интерактивное веб-приложение для подготовки к ЕНТ (Казахстан)
### Полное соответствие онлайн-системе Ustudy / НЦТ РК (Математическая грамотность + Профильная математика)

Полноценный локальный тренажёр тестирования ЕНТ (ҰБТ), точно воспроизводящий официальный интерфейс компьютерного онлайн-тестирования Национального Центра Тестирования (НЦТ) Республики Казахстан.

---

## 🚀 Способы запуска (Zero-Setup / 100% Offline)

Приложение полностью автономно и работает **локально без необходимости поднимать внешние сервера или базы данных**.

### Способ 1. Быстрый запуск (в один клик):
- Просто дважды кликните по файлу **`index.html`** (или файлу **`ЗАПУСК_ТЕСТА.bat`**).
- Приложение мгновенно откроется в вашем браузере (Chrome, Edge, Firefox, Яндекс.Браузер).

### Способ 2. Запуск через Node.js:
В терминале в папке проекта выполните:
```bash
npm run dev
```
или:
```bash
npm start
```

## 📚 Структура базы заданий (3 варианта / 150 вопросов)

Тестирование строго следует официальной спецификации НЦТ РК:
- **Блок I. Математическая грамотность (№ 1–10):**
  - 10 заданий с выбором 1 верного ответа из 4 (по 1 баллу). Пороговый балл — 3.
- **Блок II. Профильная математика (№ 11–50):**
  - **№ 11–35 (25 заданий):** выбор одного верного ответа из 4 (по 1 баллу);
  - **№ 36–40 (5 заданий):** контекстный кейс с выбором одного ответа из 4 (по 1 баллу);
  - **№ 41–45 (5 заданий):** на установление соответствия позиций А и Б из 4 вариантов (по 2 балла за верное решение, 1 балл за одну ошибку);
  - **№ 46–50 (5 заданий):** множественный выбор от 1 до 3 правильных ответов из 6 (по 2 балла за верное решение, 1 балл за одну ошибку).

### Варианты:
1. **Вариант 1 (Официальный тест НЦТ):**
   - Строго сформирован на базе прикреплённого официального файла. Включает контекст *«Агрокомплекс и геометрия теплицы»*, точные ключи и подробные пошаговые доказательства каждого задания.
2. **Вариант 2 (Тренировочный вариант):**
   - Независимый вариант с контекстным кейсом *«Инженерный проект арочного моста через реку»*, сбалансирован по всем темам школьной программы (стереометрия, тригонометрия, логарифмы, интегралы, векторы).
3. **Вариант 3 (Диагностический вариант):**
   - Углубленный вариант с контекстным кейсом *«Проектирование водонапорного резервуара»* и подробными решениями для максимальной проработки сложных тем.

## 🛠️ Возможности и функционал интерфейса

1. **Верхняя панель (Header):**
   - Переключатель вариантов (Вариант 1, Вариант 2, Вариант 3) с сохранением состояния каждого.
   - Таймер обратного отсчёта на 110 минут с визуальным предупреждением (красная подсветка и звуковой сигнал при остатке менее 10 минут).
   - Всплывающий **перетаскиваемый (draggable) инженерный калькулятор** с тригонометрией (DEG/RAD), корнями, логарифмами, степенями и скобками.
   - Модальное окно **«Справочник формул»** с вкладками (Алгебра, Тригонометрия, Логарифмы, Планиметрия, Стереометрия, Начала анализа) и мгновенным поиском.
   - Кнопка «Завершить тест» с диалоговым окном подтверждения (показывает количество отвеченных, пропущенных и помеченных заданий).

2. **Боковая сетка заданий (1–50):**
   - Индикация цветами:
     - ⬜ *Серый:* не отвечен;
     - 🟦 *Синий:* текущий активный вопрос;
     - 🟩 *Зелёный:* ответ сохранён;
     - 🟨 *Звёздочка / Флажок:* помечен «В закладки».
   - Мгновенный переход к любому заданию в 1 клик.
   - Индикатор общего прогресса (в процентах).

3. **Рабочая зона вопроса:**
   - Высококачественный рендеринг математических формул KaTeX (дроби, корни, интегралы, векторы, матрицы, степени).
   - Интерактивная радиоматрица для заданий на соответствие (41–45).
   - Чекбоксы с ограничением до 3 вариантов для множественного выбора (46–50).
   - Фиксированный блок кейса с интерактивным чертежом (SVG-схема теплицы, моста, резервуара) для контекстных задач (36–40).
   - Кнопки масштабирования шрифта (A− / A+) и добавления в закладки.

4. **Локальная надёжность (Local Persistence):**
   - Все ответы, состояние таймера, выбранный вариант и закладки автоматически сохраняются в `localStorage` вашего браузера.
   - При случайном закрытии вкладки или обновлении страницы (`F5`) ничего не потеряется!
   - Кнопка «Сбросить попытку» позволяет пройти вариант с чистого листа.

5. **Развёрнутый отчёт и экран результатов:**
   - Общий результат: количество правильных ответов (из 50) и баллы по официальной шкале НЦТ (из 60).
   - Проверка порогового балла (порог: от 3 по матграмотности, от 5 по профильной математике).
   - Детализация по блокам: «Матграмотность (из 10)» и «Профильная математика (из 50)».
   - Фильтры по статусам ответов: Все, Верные (✓), Частично верные (½), Неверные (✗), Пропущенные (—).
   - Кнопка **«Показать подробное решение»** под каждым заданием, открывающая пошаговый математический разбор.
   - Функция печати и сохранения результатов в PDF (`Ctrl + P`).
